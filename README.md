- Custom portrait with a sky-blue frame and color on hover
- SEO and structured-data metadata
- No build step required

## Run locally

Open `index.html` in a browser.

For the best local experience, you can run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This is a static site and can be deployed directly to:

- GitHub Pages
- Vercel
- Netlify

## Customization notes

The page intentionally does not include a personal email or resume because those details were not present on the public GitHub profile used for this customization.

To add a resume, place the PDF in the project folder and add a link in the hero section, for example:

```html
<a href="Jaswanth_Reddy_Naga_Resume.pdf" download>DOWNLOAD RESUME</a>
```
